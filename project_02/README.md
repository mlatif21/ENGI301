# Lightsaber PCB Design

This directory in the repository contains the files for Project02, creating a circuit board based on our implemented project using PocketBeagle. All files necessary for PCB manufacturing are found here.

The docs folder contains the project 02 proposal with mechanical block diagram. It also contains a PDF of the schematics and images of the top and bottom layers of the board.

The EAGLE folder contains the library (lbr), schematics (sch), and layout (brd) files for the PCB design.
The MFG sub-folder contains the manufacturing files (Gerber, Drill, and Assembly) generated from default CAM settings.
